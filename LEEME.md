# YAKU — Web editable

## Abrir y visualizar
1. Extrae todo el ZIP.
2. En VS Code, selecciona Archivo > Abrir carpeta > YAKU-Web.
3. Abre index.html con doble clic para visualizar la web en tu navegador.
4. Opcional: instala Live Server en VS Code y pulsa Go Live para actualizar al guardar.

No necesitas Node.js, npm, base de datos ni permisos de administrador.

## Archivos
- index.html: textos, secciones y estructura.
- style.css: diseño, colores, tipografía y adaptación móvil.
- app.js: galería, animaciones y controles.
- assets/: imágenes incluidas.

## Cambios rápidos
- Nombre: busca YAKU en index.html.
- Colores: cambia --cream, --wine y --gold en :root de style.css.
- Imágenes: reemplaza los archivos en assets conservando sus nombres.
- Textos: edita index.html y guarda en UTF-8.

Las fuentes Google requieren internet; sin conexión se usan fuentes alternativas del sistema.
Las inscripciones dentro de fotografías forman parte de la imagen original.
Esta versión es informativa y no incluye pedidos ni pagos.
